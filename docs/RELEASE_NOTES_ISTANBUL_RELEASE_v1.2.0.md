# Istanbul Release v1.2.0

OCR Advisor Foundation and multilingual provider architecture.

Highlights:

- automatic OCR necessity analysis and local engine recommendation;
- discoverable PaddleOCR, Tesseract and OCRmyPDF paths;
- reserved disabled cloud OCR and TTS API adapter slots;
- cached refreshable voice dropdown and readonly TTS-engine selector;
- auto, Chinese, English, mixed and general text profiles;
- automatic cleanup analysis with high-confidence action buttons;
- estimated current-part progress and exact overall progress;
- review-required repeated text is preserved rather than deleted.

No cloud OCR upload path is enabled. Existing v1.1.1 Windows PDF safety fixes remain active.
