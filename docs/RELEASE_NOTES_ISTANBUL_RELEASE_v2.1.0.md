# Istanbul Release v2.1.0

KR Book To Audio Istanbul Release v2.1.0 improves Windows desktop reliability and workflow clarity.

## Highlights

- suppresses child-console flashes from governed CLI tools on Windows;
- routes Poppler, FFmpeg, ffprobe, Tesseract and OCRmyPDF through one hidden-process adapter;
- records compact operation-scoped external-tool traces in Run log;
- reorganizes the interface into a sequential book-to-audio workflow;
- derives completed, running, next, optional, blocked and failed button states from the authoritative manifest;
- keeps export finalization automatic and mandatory while removing the manual Verify export button from the normal interface;
- moves manual job-folder recovery under Advanced recovery;
- adds the real Owner-machine v2.0.1 screenshot as historical public evidence.

## Compatibility

The release preserves v2.0.1 durable resume, external export verification, portable Windows onedir packaging and provider contracts.
